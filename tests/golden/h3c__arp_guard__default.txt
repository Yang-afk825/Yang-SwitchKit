# ---- 开启 ARP 检测 ----
# arp detection validate 校验 ARP 报文的 MAC 与 IP 是否自相矛盾，能挡住大部分 ARP 欺骗。
system-view
arp detection validate dst-mac ip src-mac
vlan 10
 arp detection enable
 quit
vlan 20
 arp detection enable
 quit

# ---- 指定信任端口 ----
# 上行口必须设为信任口，否则来自网关的正常 ARP 也会被丢弃。
system-view
interface GigabitEthernet1/0/24
 arp detection trust
 quit

# ---- 用户口开启 IP 源防护 ----
# 按 DHCP Snooping 绑定表校验源 IP 与源 MAC，终端私自改 IP 后报文会被直接丢弃。需要先配好 DHCP Snooping。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/22
 ip verify source ip-address mac-address
 quit

# ---- 保存配置 ----
return
save force
