# ---- 开启 IGMP Snooping ----
# 全局一条打开，再逐 VLAN 打开。
configure terminal
ip igmp snooping
ip igmp snooping vlan 10
end

# ---- 开启 IGMP 查询器 ----
# 思科的查询器默认按最小 IP 选举，多台交换机都开也没关系。
configure terminal
ip igmp snooping querier
ip igmp snooping vlan 10 querier
end

# ---- 静态指定路由器端口 ----
# 组播流量从这些口进来。不指定的话靠动态学习，上行不稳时表项容易丢。
configure terminal
ip igmp snooping vlan 10 mrouter interface GigabitEthernet1/0/24
end

# ---- 保存配置 ----
end
write memory

# [提示] 查看运行情况：show ip igmp snooping；看组播组：show ip igmp snooping groups。
