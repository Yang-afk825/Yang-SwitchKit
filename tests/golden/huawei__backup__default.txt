# ---- 先保存当前配置 ----
# save 会交互式询问是否确认，按 Y 即可。不先保存的话，备份走的是上一次保存过的配置。
system-view
save

# ---- 备份配置到服务器 ----
# 华为的启动配置文件通常是 flash:/vrpcfg.zip，部分型号为 flash:/vrpcfg.cfg，请先用 dir flash:/ 确认。
system-view
tftp 10.0.0.100 put flash:/vrpcfg.zip SW-CORE-01.cfg

# ---- 确认配置已保存 ----
# 确认当前运行配置与已保存配置一致，避免备份到过期版本。
system-view
display saved-configuration
