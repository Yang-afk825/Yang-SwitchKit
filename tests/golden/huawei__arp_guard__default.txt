# ---- 开启动态 ARP 检测（DAI） ----
# DAI 靠 DHCP Snooping 绑定表判断报文是否合法，所以 dhcp enable、dhcp snooping enable 一个都不能少。
system-view
dhcp enable
dhcp snooping enable
vlan 10
 dhcp snooping enable
 arp anti-attack check user-bind enable
 quit
vlan 20
 dhcp snooping enable
 arp anti-attack check user-bind enable
 quit

# ---- 指定信任接口 ----
# 上行口必须设为信任接口，否则来自网关的正常 ARP 也会被丢弃。
system-view
interface GigabitEthernet1/0/24
 dhcp snooping trusted
 quit

# ---- 用户口开启 IP 源防护 ----
# 按绑定表校验源 IP 与源 MAC，终端私自改 IP 后报文会被直接丢弃。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/22
 ip source check user-bind enable
 quit

# ---- 保存配置 ----
return
save
