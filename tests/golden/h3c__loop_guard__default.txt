# ---- 全局开启环路检测 ----
# 环路检测默认只记日志、不动端口，所以要显式配置处理动作。检测周期默认 30 秒，这里按填写值下发。
system-view
loopback-detection global enable vlan 10 20
loopback-detection interval-time 10
loopback-detection global action shutdown

# ---- 全局开启 BPDU 保护 ----
# 边缘端口一旦收到 BPDU，说明下面接的不是终端而是交换机，设备会直接把该端口关闭。
system-view
stp bpdu-protection

# ---- 边缘端口设为边缘口 ----
# 只有边缘端口才受 BPDU 保护管辖；上行口不要配边缘端口。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/22
 stp edged-port
 quit

# ---- 保存配置 ----
return
save force

# [提示] 被环路检测关掉的端口，可以在接口视图下 shutdown 再 undo shutdown 恢复。
# [提示] BPDU 保护：边缘端口一旦收到 BPDU（说明下面接的不是终端而是交换机）立刻关闭端口。
# [提示] 环路检测靠设备自己发探测报文，傻瓜交换机不发 BPDU，只能靠它兜底。
# [提示] 锐捷的环路检测是全局开关，不能按端口单独开关。
