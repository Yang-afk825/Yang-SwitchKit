# ---- 先保存当前配置 ----
# 不先保存的话，备份走的是上一次保存过的启动配置。
write memory

# ---- 备份配置到服务器 ----
# copy 会先问一句确认，回车即可。
copy running-config tftp://10.0.0.100/SW-CORE-01.cfg
! 上面一条把当前运行配置传到服务器；
! 想备份启动配置就换成：copy startup-config tftp://10.0.0.100/SW-CORE-01.cfg

# ---- 确认已保存 ----
# 对比一下启动配置和你以为的一致。
show startup-config
