# ---- 全局开启 DHCP Snooping ----
# check mac-address 会把 DHCP 请求里的客户端 MAC 和报文源 MAC 比对，用于拦住伪造请求。
system-view
dhcp snooping enable
dhcp snooping check mac-address

# ---- 按 VLAN 开启 ----
# 全局开关和 VLAN 开关都要打开，DHCP Snooping 才会在该 VLAN 生效。
system-view
vlan 10
 dhcp snooping enable
 quit
vlan 20
 dhcp snooping enable
 quit

# ---- 指定信任端口 ----
# 只有信任端口上收到的 DHCP 应答才会被转发，其余一律丢弃。
system-view
interface GigabitEthernet1/0/24
 dhcp snooping trust
 quit

# ---- 保存配置 ----
return
save force

# [提示] 只开 Snooping 不指定信任口，等于把所有 DHCP 应答都丢掉，配置要一次到位。
