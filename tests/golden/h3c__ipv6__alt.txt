# ---- 配置 IPv6 接口地址 ----
# Comware 默认抑制路由通告（RA），接终端的接口要 undo ipv6 nd ra halt 才能让终端自动生成地址。
system-view
interface Vlan-interface 10
 ipv6 address 2001:db8:10::1 64
 quit

# ---- 保存配置 ----
return
save force

# ---- 核对结果 ----
# 看接口地址、路由表和邻居表三项。
system-view
display ipv6 interface brief
display ipv6 routing-table
display ipv6 neighbors
