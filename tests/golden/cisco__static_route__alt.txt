# 思科最后一段是管理距离（AD），默认 1，数值越大越不优先。做浮动路由时给备份路由填一个更大的 AD，例如 200。
configure terminal
ip route 0.0.0.0 0.0.0.0 10.1.1.1
ip route 192.168.100.0 255.255.255.0 10.1.1.2
end

# ---- 下发后核对 ----

# ---- 保存配置 ----
end
