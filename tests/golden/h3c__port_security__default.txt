# ====================================================================
# H3C 新华三 | 端口安全与 MAC 绑定
# 由 Yang-SwitchKit 生成，执行前请核对版本与端口名
# ====================================================================

# ---- 全局开启端口安全 ----
# 端口安全是全局开关 + 端口参数两级配置，缺一不可。
system-view
port-security enable

# ---- 端口安全参数 ----
# autolearn 模式下端口先自动学习，学到最大值后再来新 MAC 就触发违例。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/8
 port-security max-mac-count 3
 port-security port-mode autolearn
 port-security intrusion-mode blockmac
 quit

# ---- 保存配置 ----
return
save force

# --------------------------------------------------------------------
# [风险] 端口安全不能与 802.1X、MAC 认证同时配置；开启时端口上的这两项配置会被重置。
# [风险] 安全端口不能作为镜像目的口，也不能加入聚合组。
