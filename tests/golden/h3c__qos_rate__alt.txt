# ---- 端口限速 ----
# qos lr 是接口级物理限速，直接按令牌桶对进出端口的流量整形。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/8
 qos lr outbound cir 10000
 quit

# ---- 核对限速结果 ----
# 确认 CIR 已经按要求生效。
system-view
display qos lr interface

# ---- 保存配置 ----
return
save force

# --------------------------------------------------------------------
# [风险] CIR 10000 不是 64 的整数倍，H3C 要求取 64 的倍数，建议改成 9984 或 10048。

# --------------------------------------------------------------------
# [提示] 当前限制的是出方向（用户下行）。
# [提示] CBS 太小会让 TCP 吞吐骤降，太大会失去限速意义；10 Mbps 限速可取 200000 字节。
# [提示] 入方向限的是用户上传，出方向限的是用户下载，按需求选对方向。
# [提示] 思科 / 锐捷的限速走 QoS 策略，需要先建 class-map，工具已一并生成。
