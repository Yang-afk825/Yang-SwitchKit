# ---- 开启 IGMP Snooping ----
# 先开全局，再逐 VLAN 开，两步都要做。
system-view
igmp-snooping enable
vlan 10
 igmp-snooping enable
 quit

# ---- 静态指定路由器端口 ----
# 华为的三层接口叫 Vlanif，注意与 H3C 的 Vlan-interface 区分。
system-view
interface Vlanif 10
 igmp-snooping router-port interface GigabitEthernet1/0/24
 quit

# ---- 开启快速离开 ----
# 华为把「快速离开」叫 prompt-leave，收到离开报文立即停止转发。
system-view
vlan 10
 igmp-snooping prompt-leave
 quit

# ---- 保存配置 ----
return
save
