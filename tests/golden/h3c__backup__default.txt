# ---- 先保存当前配置 ----
# 不先保存的话，备份走的是上一次保存过的启动配置，而不是你现在跑着的运行配置。
system-view
save force

# ---- 备份配置到服务器 ----
# 把设备上的启动配置文件上传到服务器。部分型号的实际文件名是 flash:/config.cfg 或 flash:/vrpcfg.zip，请先用 dir flash:/ 确认。
system-view
tftp 10.0.0.100 put flash:/startup.cfg SW-CORE-01.cfg

# ---- 确认配置已保存 ----
# 确认当前运行配置与已保存配置一致，避免备份到过期的版本。
system-view
display saved-configuration
