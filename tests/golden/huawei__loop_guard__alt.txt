# ---- 全局开启 Loop Detection ----
# 必须先开全局开关，再开 VLAN 开关，两步都做了才生效。全局开启后每个接口默认都参与检测。

loop-detection enable
loop-detection enable vlan 10 20

# ---- 保存配置 ----
return
save
