# ---- 开启 IPv6 并配置接口地址 ----
# 思科必须先 ipv6 unicast-routing，否则接口配了地址也不转发 IPv6 报文，这是最容易漏的一步。思科默认就发路由通告，不要发才用 ipv6 nd ra suppress。
configure terminal
ipv6 unicast-routing
ipv6 cef
interface Vlan10
 ipv6 enable
 ipv6 address 2001:db8:10::1/64
 ipv6 nd ra suppress
 end

# ---- 保存配置 ----
end
write memory

# ---- 核对结果 ----
# 看接口地址、路由表和邻居表三项。
show ipv6 interface brief
show ipv6 route
show ipv6 neighbors
