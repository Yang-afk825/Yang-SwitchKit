# ---- 配置 VSU 虚拟域与 VSL 链路 ----
# 锐捷的堆叠叫 VSU，互联链路叫 VSL，用 switch virtual domain 组织。两台设备分别填入各自的成员号与优先级。
configure terminal
switch virtual domain 1
 switch 1
  switch 1 priority 32
  vsl-port
   port-member interface TenGigabitEthernet 1/0/49
   port-member interface TenGigabitEthernet 1/0/50
   exit
  exit
 exit
end

# ---- 保存并激活 ----
# 部分版本需在保存后手动执行 vsl-port-configuration active 或直接重启生效，请按本机手册确认。
write
reload
