# ---- 创建聚合接口 ----
# 华为动态聚合为 mode lacp-static，静态聚合为 mode manual load-balance。
system-view
interface Eth-Trunk 1
 mode manual load-balance
 quit

# ---- 成员端口加入聚合组 ----
system-view
interface GigabitEthernet1/0/1
 eth-trunk 1
 quit
interface GigabitEthernet1/0/2
 eth-trunk 1
 quit

# ---- 保存配置 ----
# save 命令会提示确认，按 Y 继续。
return
save
