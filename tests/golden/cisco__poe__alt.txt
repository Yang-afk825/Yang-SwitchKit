# ---- 配置 PoE 供电 ----
# 思科只有 auto / never / static 三个档：auto 让设备自己协商，never 完全不供电，static 按配置功率预留。max 后面的单位是毫瓦。
configure terminal
interface range GigabitEthernet1/0/1 - 8
 power inline never
 exit
end

# ---- 核对供电状态 ----
# 确认端口在供电、实际功率是多少、预算还剩多少。
show power inline
show power inline module 1

# ---- 保存配置 ----
end
write memory

# --------------------------------------------------------------------
# [风险] power inline never 会让 AP、摄像头这类设备直接断电，确认不是生产设备再执行。

# --------------------------------------------------------------------
# [提示] 思科没有跟 H3C / 华为对应的端口供电优先级命令，供电不足时的取舍由平台自己决定，这里没有生成。
# [提示] 整机 PoE 功率是有限的，优先级决定供电不足时先牺牲哪些端口。关键设备（AP、摄像头）给 high 或 critical。
# [提示] 端口被 shutdown 时 PoE 也会断电，排查供电问题先看端口状态。
# [提示] 万兆口、光口一般不支持 PoE，配之前先确认端口类型。
