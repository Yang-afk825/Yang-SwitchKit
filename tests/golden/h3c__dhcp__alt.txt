# ---- 配置 DHCP 中继 ----
system-view
dhcp enable
interface Vlan-interface 10
 ip address 192.168.10.1 24
 dhcp select relay
 dhcp relay server-address 10.0.0.100
 quit

# ---- 保存配置 ----
return
save force

# --------------------------------------------------------------------
# [提示] 中继模式下由外部服务器分配地址，本机不建地址池。
# [提示] 服务器模式下要先在全局开启 DHCP 功能，否则地址池不生效。
# [提示] 中继模式只需在三层接口上指定服务器地址，不需要建地址池。
