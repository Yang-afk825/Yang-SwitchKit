# ---- 配置风暴控制 ----
# level 后面跟一个数字表示带宽百分比；想按包速率限就用 level pps <值>，但部分平台不支持 pps 模式，下发前用 storm-control broadcast ? 确认。
configure terminal
interface range GigabitEthernet1/0/1 - 22
 storm-control broadcast level 10
 storm-control multicast level 10
 exit
end
write memory

# --------------------------------------------------------------------
# [提示] 默认动作是丢弃超限报文、端口保持 up。
# [提示] 查看运行情况：show storm-control broadcast。
# [提示] 阈值要按现场流量来定，一开始可以按百分比给一个偏保守的值，观察后再收紧。
# [提示] 华为的百分比模式必须同时给低阈值和高阈值两个值，工具会按阈值的一半自动算低阈值。
# [提示] 同一类型的报文不要同时配风暴抑制和接口流量阈值，会冲突。
