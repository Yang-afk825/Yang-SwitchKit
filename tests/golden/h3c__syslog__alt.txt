# ---- 开启信息中心 ----
# info-center enable 是日志功能的总开关，logbuffer size 决定本地能存多少条日志。
system-view
info-center enable
info-center logbuffer size 512
clock timezone UTC add 08:00:00

# ---- 配置日志服务器 ----
# 只把 error 及以上级别的日志送到服务器，避免刷屏。
system-view
info-center source default console level error
info-center loghost 10.0.0.7
info-center source default loghost level error

# ---- NTP 时间同步 ----
# 时钟不准，日志的先后顺序就不可信了，NTP 和日志要一起配。
system-view
ntp-service enable
ntp-service unicast-server 10.0.0.5

# ---- 保存配置 ----
return
save force

# ---- 验证日志是否送达 ----
# 配完在设备上制造一条日志（比如插拔一个端口），去服务器上确认收到了。
system-view
display info-center
display logbuffer summary
