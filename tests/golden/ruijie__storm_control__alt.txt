# ---- 配置风暴抑制 ----
# level 后面跟数字表示带宽百分比；按包速率限速用 pps <值>。web 界面不支持 pps 模式，只能用命令行配。
configure terminal
interface range GigabitEthernet 1/0/1-22
 storm-control unicast pps 10
 exit
end
write

# ---- 核对结果 ----
# 确认阈值已经按填写值生效。
show storm-control
