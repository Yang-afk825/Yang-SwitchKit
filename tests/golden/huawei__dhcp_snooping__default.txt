# ---- 全局开启 DHCP 与 DHCP Snooping ----
# dhcp enable 是总开关，漏了它 DHCP Snooping 不生效。
system-view
dhcp enable
dhcp snooping enable

# ---- 在 VLAN 内开启 ----
# 华为的 DHCP Snooping 要在 VLAN 视图下逐个开启。
system-view
vlan 10
 dhcp snooping enable
 quit
vlan 20
 dhcp snooping enable
 quit

# ---- 指定信任接口 ----
# 只有信任接口上收到的 DHCP 应答才会被转发，其余一律丢弃。
system-view
interface GigabitEthernet1/0/24
 dhcp snooping trusted
 quit

# ---- 保存配置 ----
return
save
