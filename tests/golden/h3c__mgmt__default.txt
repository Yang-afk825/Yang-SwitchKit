# ---- 管理员账号与 SSH ----
# Comware V5 用 local-user 下的 level 3 指定权限，没有 user-role 概念。

ssh server enable

# ---- NTP 时间同步 ----

# ---- SNMP（v2c） ----

# ---- 保存配置 ----
return
