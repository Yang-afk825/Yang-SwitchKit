# ---- 配置保护口（protected port） ----
# 思科把端口隔离叫 protected port。保护口之间二层不通，保护口与非保护口之间正常。
configure terminal
interface range GigabitEthernet1/0/1 - 22
 switchport protected
 exit
end
write memory

# --------------------------------------------------------------------
# [风险] switchport protected 只阻挡二层互通，保护口之间仍可经三层网关互访。要连三层一起隔离，只能上 Private VLAN（隔离型 VLAN），配置模型完全不同。

# --------------------------------------------------------------------
# [提示] 上行口 GigabitEthernet1/0/24 未设为保护口，保护口与它之间可以正常通信。
# [提示] 隔离组内的端口互相不通，但与非隔离口（例如上行口）可以正常通信。
# [提示] H3C 在 IRF 组网下不支持端口隔离；华为的管理口也不支持。
# [提示] 思科 / 锐捷的 switchport protected 关闭三层隔离需要额外一条全局命令。
