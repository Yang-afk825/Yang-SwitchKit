# ====================================================================
# 华为 Huawei | 端口隔离（保护口）
# 由 Yang-SwitchKit 生成，执行前请核对版本与端口名
# ====================================================================

# ---- 端口加入隔离组 ----
# 华为不需要预先创建隔离组，直接在接口下指定组号即可，取值 1-64。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/22
 port-isolate enable group 1
 quit

# ---- 保存配置 ----
return
save

# --------------------------------------------------------------------
# [提示] 上行口 GigabitEthernet1/0/24 未加入隔离组，隔离口与它之间可以正常通信。
# [提示] 管理口不支持 port-isolate enable。
# [提示] 隔离组内的端口互相不通，但与非隔离口（例如上行口）可以正常通信。
# [提示] H3C 在 IRF 组网下不支持端口隔离；华为的管理口也不支持。
# [提示] 思科 / 锐捷的 switchport protected 关闭三层隔离需要额外一条全局命令。
