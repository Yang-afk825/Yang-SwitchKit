# ---- 配置 PoE 供电 ----
# poe priority 决定整机供电不足时的取舍顺序：critical 最后断电，low 最先断电。
configure terminal
interface range GigabitEthernet 1/0/1-8
 no poe enable
 exit
end

# ---- 核对供电状态 ----
# 确认端口在供电、功率是多少、有没有超预算。
show poe interfaces
show poe power

# ---- 保存配置 ----
end
write

# --------------------------------------------------------------------
# [风险] 关闭 PoE 会让 AP、摄像头这类设备直接断电，确认不是生产设备再执行。

# --------------------------------------------------------------------
# [提示] 整机 PoE 功率是有限的，优先级决定供电不足时先牺牲哪些端口。关键设备（AP、摄像头）给 high 或 critical。
# [提示] 端口被 shutdown 时 PoE 也会断电，排查供电问题先看端口状态。
# [提示] 万兆口、光口一般不支持 PoE，配之前先确认端口类型。
