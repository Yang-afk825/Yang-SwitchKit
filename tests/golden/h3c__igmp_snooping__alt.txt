# 由 Yang-SwitchKit 生成，执行前请核对版本与端口名

# ---- 开启 IGMP Snooping ----
# 全局打开 IGMP Snooping 后，还要在具体 VLAN 里再打开一次。
system-view
igmp-snooping
vlan 10
 igmp-snooping enable
 quit

# ---- 静态指定路由器端口 ----
# 组播流量从这些口进来。不指定的话设备靠动态学习识别，上行链路不稳定时表项容易丢。
system-view
interface Vlan-interface 10
 igmp-snooping router-port interface GigabitEthernet1/0/24
 quit

# ---- 开启快速离开 ----
# 收到离开报文立即停止转发，减少换台延迟。
system-view
vlan 10
 igmp-snooping fast-leave
 quit

# ---- 保存配置 ----
return
save force
