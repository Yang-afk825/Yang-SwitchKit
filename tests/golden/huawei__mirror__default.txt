# ---- 定义观察端口 ----
# 华为的监控口叫 observe-port（观察端口），先定义再引用。
system-view
observe-port 1 interface GigabitEthernet1/0/24

# ---- 配置端口镜像 ----
# 同一端口只能镜像到一个观察端口。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/4
 port-mirroring to observe-port 1 both
 quit

# ---- 保存配置 ----
# save 命令会提示确认，按 Y 继续。
return
save
