# ---- 创建隔离组 ----
# 隔离组编号 1-8。port-isolate mode all 表示二层三层都隔离，缺省只隔离二层、隔离口之间仍可经网关互访。
system-view
port-isolate group 1
 quit
port-isolate mode all

# ---- 端口加入隔离组 ----
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/22
 port-isolate enable group 1
 quit

# ---- 保存配置 ----
return
save force
