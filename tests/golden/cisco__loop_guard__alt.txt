# ---- 说明：思科没有环路检测（发探测帧）功能 ----
# 这一段只是说明，不会下发到设备。
! 思科没有与 H3C / 华为 / 锐捷「环路检测」对应的功能。
! 接入层防环路的正解是：生成树 + PortFast 边缘端口 + BPDU 保护 + 风暴控制。
! 下面按这套组合生成。

# ---- 确认生成树模式 ----
# 思科默认就是 rapid-pvst。全网生成树模式要统一。
configure terminal
spanning-tree mode rapid-pvst
end

# ---- 保存配置 ----
end
write memory
