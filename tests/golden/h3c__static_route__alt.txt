# ---- 配置静态路由 ----
# H3C 静态路由默认优先级 60，数值越大优先级越低。未填写优先级时不下发该字段，由设备使用默认值。
system-view
ip route-static 0.0.0.0 0 10.1.1.1
ip route-static 192.168.100.0 24 10.1.1.2

# ---- 下发后核对 ----
# 确认路由已进入路由表且下一跳可达。

display ip routing-table 0.0.0.0/0 verbose
display ip routing-table 192.168.100.0/24 verbose

# ---- 保存配置 ----
return
save force
