# ---- 配置静态路由 ----
# 华为静态路由默认优先级 60，数值越大优先级越低。
system-view
ip route-static 0.0.0.0 0 10.1.1.1
ip route-static 192.168.100.0 24 10.1.1.2

# ---- 下发后核对 ----
system-view
display ip routing-table 0.0.0.0
display ip routing-table 192.168.100.0

# ---- 保存配置 ----
# save 命令会提示确认，按 Y 继续。
return
save
