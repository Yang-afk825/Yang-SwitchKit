# ---- 配置优先级信任模式 ----
# dot1p 是二层 802.1p，报文必须带 VLAN Tag 才有；dscp 是三层 IP 报文里的标记。Comware V5 的命令写作 priority-trust cos / dscp，与 V7 不同。
system-view
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/24
 qos trust dscp
 quit

# ---- 保存配置 ----
return
save force

# ---- 核对结果 ----
# 确认信任模式生效、策略有命中计数。
system-view
display qos trust interface
display qos policy interface

# [提示] 不做标记的网络里，所有报文的优先级其实都一样，所以语音、视频这类业务要在接入层就打上 DSCP。
# [提示] 优先级信任要配在接入侧的端口上，且要在策略应用之前配好，否则后面的分类拿不到有效输入。
# [提示] 默认设备是不信任报文优先级的，会用端口优先级给所有流量兜底，所以不做标记的网络里大家的优先级其实都一样。
# [提示] 语音、视频这类业务建议在接入层就打 DSCP 标记，后面全程信任，比在核心层再分类省事得多。
