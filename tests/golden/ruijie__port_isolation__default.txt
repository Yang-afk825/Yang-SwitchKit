# ---- 配置保护口（端口隔离） ----
# 锐捷把端口隔离叫保护口/protected port。protected-ports route-deny 是全局开关，开了之后保护口之间连三层路由也不通，不能按端口单独设置。
configure terminal
interface range GigabitEthernet 1/0/1-22
 switchport protected
 exit
end
write

# ---- 核对结果 ----
# 列出当前已设为保护口的接口。
show protected-ports

# --------------------------------------------------------------------
# [提示] 上行口 GigabitEthernet 1/0/24 未设为保护口，保护口与它之间可以正常通信。
# [提示] 保护口只支持以太网物理接口与聚合口；聚合口设为保护口后，其成员口一并生效。
# [提示] 隔离组内的端口互相不通，但与非隔离口（例如上行口）可以正常通信。
# [提示] H3C 在 IRF 组网下不支持端口隔离；华为的管理口也不支持。
# [提示] 思科 / 锐捷的 switchport protected 关闭三层隔离需要额外一条全局命令。
