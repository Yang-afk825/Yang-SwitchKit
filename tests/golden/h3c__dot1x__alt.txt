# ---- 配置 RADIUS 方案 ----
# user-name-format without-domain 表示用户名不带 @域名 后缀发给服务器，多数 RADIUS 服务器都按这种格式建账号。
system-view
radius scheme SCG-RADIUS
 primary authentication 192.168.1.30
 key authentication simple Radius@123
 user-name-format without-domain
 quit

# ---- 把认证域指向 RADIUS 方案 ----
# 认证域负责把接入用户引到指定的 RADIUS 方案上。
system-view
domain scg.local
 authentication lan-access radius-scheme SCG-RADIUS
 authorization lan-access radius-scheme SCG-RADIUS
 quit

# ---- 全局与端口开启 802.1X ----
# H3C 要开两处：全局一条 dot1x，接口下再来一条 dot1x，少任何一处端口都不会触发认证。
system-view
dot1x
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/8
 dot1x
 dot1x port-method portbased
 dot1x port-control unauthorized-force
 dot1x mac-bypass
 quit

# ---- 保存配置 ----
return
save force

# ---- 核对认证状态 ----
# 先看端口是不是在跑 802.1X，再看有没有在线用户。
system-view
display dot1x
display dot1x connection

# [风险] MAC 旁路认证等于给哑终端开了一个口子，MAC 地址是能伪造的，只建议用在打印机、摄像头这类固定设备上。
# [风险] 802.1X 不能与端口安全同时配置，H3C 上开端口安全会重置 802.1X 相关配置。
