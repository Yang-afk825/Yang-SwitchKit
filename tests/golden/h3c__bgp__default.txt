# ---- 配置 BGP 与邻居 ----
# Comware V7 必须在 address-family ipv4 unicast 里再 peer enable 一次，只创建邻居不激活，会话建不起来。
system-view
bgp 65001
 router-id 1.1.1.1
 peer 10.0.0.2 as-number 65002
 peer 10.0.0.3 as-number 65003
 address-family ipv4 unicast
  peer 10.0.0.2 enable
  peer 10.0.0.3 enable
  network 192.168.10.0 255.255.255.0
  quit
 quit

# ---- 保存配置 ----
return
save force

# ---- 核对邻居与路由 ----
# State 要是 Established，路由表里要有你要的网段。
system-view
display bgp peer ipv4
display bgp routing-table ipv4
