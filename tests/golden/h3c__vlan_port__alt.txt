# ---- 创建 VLAN ----
system-view
vlan 10
 quit
vlan 20
 quit
vlan 30
 quit

# ---- 配置 Trunk 端口 ----
interface range GigabitEthernet1/0/1 to GigabitEthernet1/0/8
 port link-type trunk
 port trunk permit vlan all
 quit

# ---- 保存配置 ----
return
save force

# --------------------------------------------------------------------
# [风险] Trunk 放通全部 VLAN 会把广播域铺满，若不必要请改成明确的 VLAN 列表。
