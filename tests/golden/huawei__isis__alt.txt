# ---- 启用 IS-IS 并配置 NET ----
# 官方建议 cost-style、is-level、network-entity 三条一起改时把 network-entity 放最后，避免配置顺序不对导致 IS-IS 进程重启。
system-view
isis 1
 is-level level-2
 cost-style narrow
 network-entity 49.0001.0000.0000.0001.00
 quit

# ---- 接口使能 IS-IS ----
# 只能建单层邻接时用 isis circuit-level 限制。华为还支持 hmac-sha256，写法是 isis authentication-mode hmac-sha256 key-id 1 cipher <密钥>。
system-view
interface Vlanif10
 isis enable 1
 isis circuit-level level-2
 isis authentication-mode md5 plain Isis@2026
 quit
interface Vlanif20
 isis enable 1
 isis circuit-level level-2
 isis authentication-mode md5 plain Isis@2026
 quit

# ---- 保存配置 ----
return
save

# ---- 核对邻居与路由 ----
# 先看邻接是不是 Up，再看路由表里有没有学到对端网段。
system-view
display isis peer
display isis route
display isis lsdb
